# CPX for VS Code

Competitive programming inside VS Code: Codeforces, CSES, and AtCoder.

- **CPX: Open Problem from URL**: paste a problem link to get a solution file with its samples
- **CPX: Run Samples for Active File**: compile, run every sample, see per-sample verdicts beside your code
- **CPX: Show Statement**: the problem statement in a side panel
- **CPX: Copy Code and Open Submit Page**: CPX never submits for you

Settings: `cpx.defaultLanguage` (cpp or python), `cpx.workspaceFolder`, `cpx.cppCompiler`,
`cpx.pythonPath`, `cpx.timeLimitMs`.

Part of [CPX](https://github.com/adarsh-67r/cpx). MIT licensed.
